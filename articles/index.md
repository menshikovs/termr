# Articles

### Build and test terminal applications

- [Build a Terminal UI in R with
  termr](https://menshikovs.github.io/termr/articles/getting-started.md):

  Install termr, compose a terminal form in R, handle keyboard events,
  and verify the app with a headless test.

- [Building Interactive Terminal Dashboards in
  R](https://menshikovs.github.io/termr/articles/terminal-dashboards.md):

  Build a keyboard-driven R terminal dashboard with a sortable in-memory
  data table, selection events, and headless interaction checks.

- [Testing Terminal UI Applications in
  R](https://menshikovs.github.io/termr/articles/testing-terminal-ui.md):

  Use termr’s headless driver to simulate keyboard input and inspect
  rendered terminal output in deterministic R application tests.
