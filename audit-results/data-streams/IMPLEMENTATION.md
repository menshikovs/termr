# Implementation

## New maintained files

- R/streams.R: pure R stream factory and roxygen source.
- man/termr_stream.Rd: generated help; NAMESPACE export generated by
  `Rscript tools/dev.R doc` in WSL. WSL roxygen 7.3.3 reformatted unrelated
  R6 documentation; those changes were restored to their original Git content from HEAD plus
  INITIAL-CHANGES.patch, preserving the user's original help edits. The
  generated stream topic and export are retained.
- tests/testthat/test-streams.R: configuration, retention, model invariants,
  subscription mutation, errors, close, signal isolation, finalizer-based
  resource release, 100000 emissions with 10 subscribers.
- tests/testthat/test-monitor-live.R: immutable version publication, schema,
  rate/retention limits, stale/corrupt/missing recovery, sequence gaps,
  restart, real metrics, TUI headless and Shiny testServer integration.
- inst/examples/system-monitor-live/: common.R, collector.R, tui.R,
  shiny-app.R and README.md; independent entry points, documented paths and
  cleanup. No changes to the existing synthetic system-monitor.R.
- tools/data-streams-integration{,-child}.R: separate-process lifecycle and
  concurrent-read verification against an installed checkout.
- docs/data-streams.md: public guide.

## Modified maintained files

DESCRIPTION adds shiny to Suggests; jsonlite was already optional and ps was
already an Import. No mandatory dependency added. .Rbuildignore excludes all
audit-results. README, NEWS, docs/reactivity.md, docs/stability.md and
docs/api-inventory.md link/classify the new API. NAMESPACE gains one export.
Other initially modified files are outside this task and were preserved.

Reports, reproducible drivers, logs, profiles and scratch libraries reside
only under audit-results/data-streams and are excluded from package builds.
Build drivers stage the same unignored source entries before R CMD build,
because build first copies the whole tree (including ignored large existing
tools scratch directories) before applying ignore rules. Tarball inspection
asserts that audit reports and temporary publication files are absent.

No commit, push, merge or release was performed. No system software or R
packages were installed globally; test installations use scratch libraries
inside the workspace.
