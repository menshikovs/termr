# Clipboard и команды DataTable

Добавлены три действия в существующий command palette, список команд и help:

- **Copy selection as R value** — выделенная ячейка или строки и видимые
  колонки в пределах лимитов;
- **Copy current R pipeline** — код для поддерживаемого текущего локального
  фильтра, сортировки, row selection и порядка видимых колонок;
- **Copy local R edits** — локальные правки по исходным индексам строк.

Действия доступны из текущего command palette (Ctrl+P). Новые комбинации
клавиш не назначены. Обычный Ctrl+C продолжает копировать TSV через прежний
clipboard путь. Поэтому существующие сценарии вставки в spreadsheet не
меняются.

`$copy_reproducible_code()` возвращает результат генератора и передаёт текст
в существующий clipboard механизм только при пригодном `exact` коде. При
отказе/лимите возвращается объяснение; неподдерживаемый код молча не
копируется. Проверены наличие команд и отсутствие новых shortcuts в тестах.

Фактическая latency системного clipboard и поведение RStudio Terminal /
Positron не измерялись: проверки шли без прикреплённого интерактивного
терминала. Windows и WSL проверяют генерацию и командную интеграцию, не
перенося clipboard-поведение одного terminal host на другой.
