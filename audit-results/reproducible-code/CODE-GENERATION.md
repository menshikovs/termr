# Генерация R-кода

## Построение выражений

Реализация находится в `R/reproducible-code.R`. Calls, names, namespaced
functions и блоки создаются как R language objects. Завершающий этап применяет
`deparse()` к проверенному AST. Пользовательские имена колонок остаются
строковыми аргументами `[[`/`[`, а не становятся R-символами.

Строковые и атомарные литералы экранируются из R-значений с помощью `dput()`;
его вывод разбирается только как литерал, который создан самим сериализатором.
Фиксированные токены `NA`, `NULL`, `NaN`, `Inf` разбираются из констант,
заданных внутри модуля. Пользовательский текст не передаётся в
`eval(parse(text = user_input))`; сгенерированный код пакет сам не исполняет.

Числа с плавающей точкой записываются с достаточной точностью; спец-значения,
tagged NA и `integer64` получают отдельные представления. Атрибуты whitelist
классов восстанавливаются через `structure()` или публичный/валидированный
конструктор. S4 Period/Duration/Interval создаются через
`methods::new()` с исходными слотами. Требуемые optional-пакеты проверяются
guards перед выражением.

## Результат

`DataTable$reproducible_code(kind, max_rows, max_bytes)` возвращает объект с
полями `code`, `status`, `reason`, `packages`, `requires_source_binding` и
bounded `model`.

| Статус | Значение |
|---|---|
| `exact` | Сгенерирован проверенный код для поддержанного объекта/снимка |
| `limited` | Сработал лимит строк, ячеек, edit ledger или размера исходника |
| `unsupported` | Нет безопасного представления для класса/фильтра/источника |

Лимиты: по умолчанию 1,000 строк, 10,000 ячеек и 1 MB кода/значений;
жёсткие пределы — 5,000 строк и 5 MB. Edit ledger хранит до 1,000 уникальных
ячеек, а рекурсивная глубина сериализации — до 40.

## Минимальное использование

```r
code <- table$reproducible_code("pipeline")
if (identical(code$status, "exact")) {
  data <- original_frame
  cat(code$code)
}
```

Пример печатает исходник для просмотра/копирования; он не запускается
пакетом. Используйте результат только после проверки привязки `data` и
содержимого кода.
