# Переход к следующей фазе

## Готово для продолжения

A4 даёт ограниченный local-code export без зависимости от новой модели
источника. Следующую фазу можно строить поверх явно обозначенного символа
`data` и текущей модели вида. Вывод pipeline нельзя считать идентичностью
источника или полной историей действий.

## Что понадобится будущей интеграции `inkr`

- стабильный source binding с явной версией/идентификатором и редактируемой
  политикой раскрытия;
- typed operation history отдельно от временного UI state;
- адаптеры backend query с собственными тестами семантики и безопасности;
- политики для изменённых данных, строковых ключей и восстановления
  источника;
- договорённость о том, какие выражения можно автоматически передавать
  независимому инструменту.

До появления этих контрактов используйте A4 как средство получить,
просмотреть и вручную проверить R-код для локальных объектов. Автоматическая
передача кода или remote query не является частью текущего API.

WSL package check на текущем результате прошёл. Полное Windows R CMD check
ограничено отказом sandbox на processx child pipes, а PTY harness имеет два
неразрешённых combined-focus отказа, связь которых с A4 не установлена.
Следующую фазу архитектурно можно начинать, но эти два результата остаются
открытыми валидационными пунктами и не считаются зелёными.
