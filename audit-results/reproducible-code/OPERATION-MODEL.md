# Модель операций

## Четыре разных понятия

| Область | Текущее представление | Экспорт |
|---|---|---|
| View state | Базовые row indices, фильтры, сортировка, порядок/видимость колонок, выделенный диапазон | Pipeline описывает текущий итоговый локальный вид |
| Operation history | DataTable не записывал временную последовательность действий до A4 | История не заявляется и не синтезируется |
| Data mutations | Bounded список локальных изменений: исходный row index, колонка, начальное и конечное значение | Код назначает конечные значения по исходным индексам |
| Source identity | Текущий `table_source` не имеет публичной переносимой идентичности для R-кода | Используется символ `data`; query/connection/path не экспортируются |

Публичная сводка модели не включает closures функций-фильтров и не копирует
значения пользовательских фильтров в metadata результата. Параметры
необходимые для построения кода находятся во внутреннем состоянии до
проверки и генерации.

## Правила переходов

- Выбор диапазона строк — часть состояния вида; обычный курсор и scroll — нет.
- Сброс фильтра/сортировки меняет текущее состояние. Предыдущий фильтр или
  сортировка не остаются в несуществующем журнале.
- Search и terminal navigation не становятся шагами pipeline.
- Правки после сортировки/фильтрации записываются по исходному индексу данных,
  а не по экранной позиции.
- Повторная правка той же ячейки заменяет конечное значение. Возврат к
  исходному значению удаляет запись.
- Смена данных очищает edit ledger. Source-backed edit export отклоняется;
  запись в удалённый источник не выполняется.
- После достижения 1,000 уникальных правок новые записи не увеличивают ledger;
  экспорт сообщает `limited`, если полнота журнала уже потеряна.

## Воспроизведение

Значения выделения — standalone R-объект (`requires_source_binding = FALSE`).
Pipeline и правки используют символическую переменную `data` и возвращают
`requires_source_binding = TRUE`. Для точного результата caller должен
привязать `data` к тому же объекту и версии входных данных. Внешняя
идентичность и происхождение этого объекта не угадываются.

Pipeline сохраняет стабильную сортировку, направление каждого ключа,
`NA` в конце, поддерживаемые фильтры, явный диапазон строк и видимые колонки
в их текущем display order. Фильтр, заданный функцией, имеет статус
`unsupported`: сериализация closure не является переносимым контрактом.
