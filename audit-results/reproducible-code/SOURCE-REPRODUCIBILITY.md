# Источники данных и воспроизводимость

## Локальный DataTable

Pipeline и экспорт локальных изменений используют имя `data` как явную
привязку источника. Пользователь должен перед запуском связать его с тем же
объектом, из которого создан DataTable. Код не встраивает всю исходную таблицу
в pipeline и не подменяет отсутствующую идентичность случайным глобальным
объектом.

Локальное редактирование воспроизводится по исходным row indices. После
фильтрации и сортировки визуальная позиция не используется. Индекс относится
к исходной версии `data`; при перестановке или замене строк правки могут
примениться к другой записи, поэтому без идентификатора строки гарантии
между версиями данных нет.

## `table_source` и удалённые данные

Текущий `table_source` не публикует безопасную переносимую идентичность,
которую можно было бы поместить в R-код. Поэтому:

- pipeline для `table_source` возвращает `unsupported` и
  `requires_source_binding = TRUE`;
- edits для источника не экспортируются и не записываются;
- selection может экспортироваться только для фактически полученных
  выбранных строк, если schema и результат чтения сохраняют class/storage;
- источник не сканируется целиком ради небольшой выборки;
- путь, SQL, параметры соединения и credentials не добавляются в результат.

При необходимости пользователь может вручную предоставить безопасное имя
`data` для заранее подготовленного объекта. Генератор не удостоверяет, что
эта привязка ссылается на исходный backend.

## DuckDB/dbplyr и Arrow

Прямых DataTable адаптеров для dbplyr/DuckDB и Arrow Dataset в этой версии
нет. Существующие примеры выполняют явный ограниченный `collect()` выборки и
передают полученный локальный frame в DataTable. Pipeline воспроизводит
операции над этим frame, а не исходный SQL/query, базу или Arrow Dataset.
`inst/examples/reproducible-code.R` содержит optional-примеры и проверяет
наличие пакетов до использования; они не претендуют на query export.

Восстановить исходный SQL, lazy plan, parquet path или свежие backend-данные
может только отдельный контракт источника с безопасным symbolic binding и
описанием версии/идентичности источника. Он выходит за пределы A4.
