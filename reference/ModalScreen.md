# Modal screen

A screen drawn over the current one. See
[`modal()`](https://menshikovs.github.io/termr/reference/modal.md).

## Super classes

[`Widget`](https://menshikovs.github.io/termr/reference/Widget-class.md)
-\> [`Screen`](https://menshikovs.github.io/termr/reference/Screen.md)
-\> `ModalScreen`

## Public fields

- `dim`:

  Dim the screens below?

- `dismissable`:

  Close with Escape?

- `on_dismiss`:

  `NULL` or `function(result, app)` called when the screen is dismissed.

### `ModalScreen$new()`

Create a modal screen. See
[`modal()`](https://menshikovs.github.io/termr/reference/modal.md).

#### Usage

    ModalScreen$new(
      ...,
      dim = TRUE,
      dismissable = TRUE,
      on_dismiss = NULL,
      id = NULL,
      classes = NULL,
      style = NULL
    )

#### Arguments

- `...`:

  Child widgets.

- `dim, dismissable`:

  See fields.

- `on_dismiss`:

  Callback.

- `id, classes, style`:

  See
  [Widget](https://menshikovs.github.io/termr/reference/Widget-class.md).

------------------------------------------------------------------------

### `ModalScreen$default_style()`

### `ModalScreen$default_bindings()`

### `ModalScreen$dismiss()`

Close the screen, passing `result` to the callbacks.

#### Usage

    ModalScreen$dismiss(result = NULL)

#### Arguments

- `result`:

  Any value.

------------------------------------------------------------------------

### `ModalScreen$action_dismiss()`

Action used by the Escape binding.

#### Usage

    ModalScreen$action_dismiss()

- `deep`:

  Whether to make a deep clone.
