# Select widget

A drop-down choice. See
[`dropdown()`](https://menshikovs.github.io/termr/reference/dropdown.md).

## Super class

[`Widget`](https://menshikovs.github.io/termr/reference/Widget-class.md)
-\> `Select`

## Public fields

- `focusable`:

  Selects can be focused.

- `prompt`:

  Text shown when nothing is selected.

## Active bindings

- `value`:

  The selected value or `NULL` (reactive; sends `"dropdown.changed"`).

- `choices`:

  The choice values.

### `Select$new()`

Create a select. See
[`dropdown()`](https://menshikovs.github.io/termr/reference/dropdown.md).

#### Usage

    Select$new(
      choices,
      value = NULL,
      prompt = "Select",
      id = NULL,
      classes = NULL,
      style = NULL,
      disabled = FALSE
    )

#### Arguments

- `choices`:

  Choices.

- `value`:

  Initial value.

- `prompt`:

  Prompt.

- `id, classes, style, disabled`:

  See
  [Widget](https://menshikovs.github.io/termr/reference/Widget-class.md).
